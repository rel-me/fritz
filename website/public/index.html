Native for macOS

A familiar for your code.

Fritz is a native Mac app for talking with language models and putting them to work in your projects. It reads files, makes edits, runs commands, and checks the results — keeping every step on the record.

Download for Mac See it work

Requires macOS 15 or later.

01The app

Chat while you think.
Code when it’s time.

Each project keeps its own threads, and each thread keeps its own transcript, draft, and model. Switch a thread to Code and Fritz works inside the project folder with native tool calls, showing each read, edit, and command as it happens.

  • Projects and threads

    Your folders in the sidebar, their conversations beneath them. Transcripts, drafts, and the selected thread come back when you relaunch.

  • Chat or Code

    Chat is a streaming conversation without tools. Code reads, edits, and runs commands in the project until it can answer.

  • Nothing out of sight

    Tool activity stays attached to the reply that produced it. Press Escape to stop a run and the commands it started.

Run one on this Mac

Offline, on Metal, with no API key.

Download a model from inside Fritz and chat with it through llama.cpp — no Ollama, no background server. Downloads are pinned to exact revisions and verified by SHA-256 before use.

When your other tools need it, start a loopback-only API for that model from Settings.

Local models support Chat. Code needs a provider with native tool calling.

03Principles

Built like a Mac app.
Behaves like a guest.

  1. Keys stay in the Keychain

    Provider keys live in Fritz’s own Keychain namespace — never in config files, command-line arguments, environment variables, or logs.

  2. Native all the way down

    SwiftUI and AppKit up front, a Rust runtime behind it. No embedded browser engine.

  3. One process per chat

    Each conversation runs in its own harness process, supervised by the app over private pipes rather than a local web server.

  4. Every run has limits

    By default a run stops after 24 model turns, 64 tool calls, or 10 minutes. Fritz never commits or rolls back on your behalf.

A note on trust. Commands run with your macOS user permissions. The project folder is a working directory, not a sandbox, so use Code with projects you trust.

04Terminal

Also answers from the shell.

The fritz command shares the app’s providers and saved keys. Install it from Settings → General → Command Line.

# Work in a project from the shell
$ fritz chat "Fix the failing test" --project .

# Install a local model and serve it on loopback
$ fritz local-models install qwen3-0.6b-q4_k_m
$ fritz local-models serve --port 11435
