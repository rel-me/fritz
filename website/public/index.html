A familiar for your code.

Fritz is a Mac app that puts language models to work in your projects. It reads files, makes edits, runs commands, and checks the results.

03Terminal

Also answers from the shell.

Install the fritz command from Settings → General → Command Line.

# Work in a project from the shell
$ fritz chat "Fix the failing test" --project .

# Install a local model and serve it
$ fritz local-models install qwen3-0.6b-q4_k_m
$ fritz local-models serve
