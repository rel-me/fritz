# Speed up Fritz CI

## User request

> Speed  up fritz CI, it's really slow

Follow the supplied AGENTS.md instructions: create a branch and PR, commit and
push the changes, and monitor the PR in a sub-agent, fixing failures. Monitor
again after changes to a previously successful PR.

## Delegated monitoring prompt

Monitor the PR for this change at its latest pushed commit. Wait for all required
CI checks to finish; inspect failures and fix those caused by this change.
Preserve unrelated changes and the dedicated runner account and session/cache
lock ordering. Do not merge the PR. Report check results, timings, and any exact
external or pre-existing blockers. If you push a fix, monitor the new commit too.
Append any follow-up delegated prompts to this file. Coordinate with the parent
before making edits or commits.
