# Notifications and feedback

Match feedback to the event and the user's requested notification behavior.
Routine progress should not create repeated interruptions. Errors need enough
context and a concrete recovery action when available, in the existing feedback
area outside grouped cells.

Use alerts when a decision or interruption is warranted; do not demand an alert
for every catch block. Suppression options suit optional recurring information,
not required decisions. Respect notification permission and preferences. Badges
and completion messages should convey useful state rather than add visual noise.
