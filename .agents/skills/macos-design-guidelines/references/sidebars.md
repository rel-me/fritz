# Sidebars and inspectors

Preserve Fritz's existing navigation and native selection behavior. Keep rows
readable and lightweight; richer metadata belongs in the detail surface. Check
long titles, selection after deletion/filtering, resizing, and restoration.

Use disclosure for actual hierarchy. Reordering, badges, and multiple selection
should reflect supported user operations, not be added automatically. Keep empty
sections quiet and reserve cells for controls/actions/records as required by
AGENTS.md. Verify collapse and focus behavior where the sidebar can be hidden.
For implementation patterns, use the existing swiftui-patterns reference.
