# Selection and presentation

Trace the selected session/page or record from its owner into each window,
sidebar, sheet, and inspector. Verify closing, deleting, restoring, and switching
records cannot show stale content or apply an action to the wrong record.

Choose presentation state that keeps the selected payload and visibility
consistent. Item-based sheets can help, but an existing Boolean presentation is
not a defect without a reachable mismatch. Test repeated activation and dismissal,
including cancellation and unsaved edits.

Keep commands routed to the intended window and responder. Do not prescribe a
new navigation container merely to modernize syntax. Use the implementation
skill's windowing reference for actual scene changes and the HIG skill for
keyboard/focus conventions.
